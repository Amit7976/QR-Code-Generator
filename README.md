# 🔳 QR Code Generator

A sleek and simple **QR Code Generator** built using **HTML**, **CSS**, and **JavaScript**.  
Enter any text, link, or info — and instantly generate a scannable QR code, right in your browser.

🌐 **Live Demo**: [Generate a QR Code](https://amit7976.github.io/QR-Code-Generator/)

---

## ✨ Features

- ✍️ Input any custom text or URL  
- ⚡ Generates QR code in real-time  
- 📷 Scannable with any mobile QR scanner  
- 💾 Downloadable QR image (if implemented)  
- 📱 Clean, responsive design — works on mobile & desktop

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- External QR API (`api.qrserver.com`)
